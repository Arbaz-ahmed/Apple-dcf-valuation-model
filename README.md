# Apple Inc. | Financial Modelling & DCF Equity Valuation

**Independent financial analysis project** | Microsoft Excel, company financial statements, five-year forecasting and discounted cash flow (DCF) valuation.

## Project deliverables

- [Apple_Financial_Model.xlsx](Apple_Financial_Model.xlsx) — working financial model and calculations.
- [Apple_Valuation_Report.pdf](Apple_Valuation_Report.pdf) — two-page portfolio summary of methodology, assumptions and results.

## What the model does

1. Analyses Apple's FY2024–FY2026 historical financial performance, including revenue, margins and free cash flow.
2. Projects financial performance over FY2027–FY2031.
3. Estimates the present value of projected free cash flows and a terminal value using a DCF model.
4. Translates enterprise value into an estimated equity value and intrinsic value per share under the stated assumptions.

## Key illustrative assumptions and outputs

| Measure | Model value |
|---|---:|
| Weighted average cost of capital (WACC) | 9.0% |
| Terminal perpetual growth | 2.5% |
| Estimated equity value | $2.39 trillion |
| Estimated intrinsic value per share | $164.50 |

These are **model outputs, not observed market prices or investment advice**. The valuation depends materially on the chosen discount rate and terminal growth assumptions. The report notes that approximately 74.6% of enterprise value comes from terminal value, which makes the valuation particularly sensitive to long-run forecasts.

## How to review

1. Open the [two-page report](Apple_Valuation_Report.pdf) to understand the findings and limitations.
2. Open the Excel workbook to examine historical inputs, forecast formulas and DCF calculations.
3. Change the model assumptions in a copy of the workbook to explore how your valuation changes.
